ПУБЛИКАЦИЯ НА VERCEL С MAC

1. Распакуйте архив.
2. Откройте приложение «Терминал».
3. Введите cd, поставьте пробел и перетащите распакованную папку в окно Терминала.
4. Нажмите Enter.
5. Выполните команду:

   npx vercel login

6. После входа выполните:

   npx vercel --prod

7. На вопросы Vercel отвечайте:
   Set up and deploy? — Y
   Which scope? — выберите свой аккаунт
   Link to existing project? — N
   Project name — uplotnitel23
   In which directory is your code located? — ./
   Modify settings? — N

После сборки Vercel покажет ссылку вида https://uplotnitel23.vercel.app

ВАЖНО

Это демонстрационная версия для показа клиенту. Главная страница, каталог,
поиск, фильтры и информационные страницы работают. Для рабочей админ-панели,
регистрации и постоянной загрузки фотографий нужно отдельно подключить базу
данных и файловое хранилище на Vercel.
