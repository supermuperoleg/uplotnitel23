ПУБЛИКАЦИЯ НА VERCEL С MAC

1. Распакуйте архив.
2. Откройте приложение «Терминал».
3. Введите cd, поставьте пробел и перетащите распакованную папку в окно Терминала.
4. Нажмите Enter.
5. Выполните команду: npx vercel login
6. После входа выполните: npx vercel --prod
7. На вопросы Vercel отвечайте:
   Set up and deploy? — Y
   Which scope? — выберите свой аккаунт
   Link to existing project? — N
   Project name — uplotnitel23
   In which directory is your code located? — ./
   Modify settings? — N

После сборки Vercel покажет ссылку вида https://uplotnitel23.vercel.app

ПОДКЛЮЧЕНИЕ БАЗЫ ДЛЯ РЕГИСТРАЦИИ ПОКУПАТЕЛЕЙ

1. Откройте проект в Vercel.
2. Перейдите в Storage или Marketplace.
3. Найдите Neon Postgres и нажмите Add Integration.
4. Создайте бесплатную базу и подключите её к проекту uplotnitel23.
5. Проверьте в Settings → Environment Variables, что появилась переменная DATABASE_URL.
6. Откройте Deployments, нажмите три точки у последней версии и выберите Redeploy.

Таблицы покупателей и сессий создадутся автоматически при первой регистрации.
Пароли сохраняются только как защищённые хэши. Покупательский аккаунт не даёт
доступ к административной панели.

ПРОВЕРКА

1. Откройте /account и зарегистрируйтесь по электронной почте.
2. Пароль должен содержать от 6 до 72 латинских букв или цифр.
3. Откройте /catalog, добавьте товар и проверьте счётчик корзины в шапке.
4. Откройте /cart и проверьте состав заказа.

ПРИМЕЧАНИЕ

Для постоянной загрузки фотографий через административную панель потребуется
отдельно подключить файловое хранилище Vercel Blob.
